Content Quality Tooling

#powershell #python #automation

Context

Some documentation quality issues only became visible during the publishing process — internal PDF cross-references that didn't work as expected, and Unicode and encoding issues introduced during content migrations.

I built two small PowerShell and Python tools to detect and address these issues, since checking dozens of guides manually was not practical.

My role

I identified both problems, investigated their underlying causes through testing, and independently built both tools, using AI assistance for the code.

Cross-reference validation

Some internal cross-references worked correctly in Confluence but, after PDF export, opened the Confluence page instead of the corresponding section in the PDF. This is a documented Confluence export behavior affecting internal and anchor links.

I built a PowerShell tool to scan exported HTML for links that incorrectly pointed back to Confluence. I also adapted it to scan the exported PDFs, allowing the same issue to be checked both before and after export.

After validating the approach, I used the HTML check as part of the regular workflow to catch affected links before generating the PDFs.

The core detection logic:
$confluenceLinkPattern = 'href="(https://[^"]*\.atlassian\.net/wiki/[^"]+)"'
Finding the issue was only part of the work. I tested different approaches to identify a reliable fix and documented the findings in the tool's generated report.

Unicode & encoding cleanup

Content migrated between platforms sometimes contained corrupted characters caused by encoding problems. These issues, often appearing as mojibake, were difficult to identify and correct manually across large amounts of content. I built a Python tool using the Confluence REST API to find and clean up these patterns across a space or page tree.

Because the tool writes changes back to live Confluence pages, safety was a key consideration. A dry-run mode previews every change before it is applied, while a protection step shields code blocks, panels, and other structured macros from text replacements.

Safety checks in the cleanup script
DRY_RUN = True  # ALWAYS start with True — review the printed preview
                 # of every change before ever setting this to False.

# Confluence storage format tags to protect from replacement
PROTECTED_TAGS = [
    (..., "code macro"),
    (..., "panel macro"),
    (..., "inline code"),
    (..., "pre block"),
]

Result

Both tools turned manual quality checks into repeatable checks that could run across an entire documentation set in minutes — one detecting broken cross-references before PDF export, the other cleaning up encoding issues without altering protected content.
