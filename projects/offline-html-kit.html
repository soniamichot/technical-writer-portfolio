Offline HTML Documentation Kit

#distribution #offline #config-driven

Context

Some deployments of the product run in air-gapped environments, where users cannot access the online customer portal and need documentation that can be installed and used entirely offline.

PDF was available as an offline format, but HTML offered a more navigable documentation experience, with the familiar structure and interaction of online documentation while remaining fully offline.

My role

I identified the need for a more practical offline documentation experience and designed and built a self-contained documentation kit to address it. I used AI-assisted coding throughout the project to explore implementation approaches, develop the tooling, and troubleshoot issues along the way.
